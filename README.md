# SONOLAB

Um sistema ágil e interativo de sonoplastia desenvolvido em HTML, CSS e JavaScript puro. Foi idealizado especialmente para o controle de efeitos sonoros, trilhas musicais e ambiências em peças de teatro, podcasts e apresentações ao vivo.

## Principais Funcionalidades

- **Roteiro da Peça Integrado:** Conta com um painel inteligente onde você pode adicionar as falas dos atores ou indicações de cena (cues). É possível vincular cada fala a um efeito sonoro específico, permitindo disparar os áudios exatos clicando apenas no botão de play da cena correspondente.
- **Soundboard Interativo:** Organize e reproduza facilmente seus áudios. Filtre as faixas por categorias (Efeitos, Ambiente, Músicas).
- **Upload Local de Áudios:** Carregue os seus próprios arquivos de som do computador de forma rápida.
- **Controles Rápidos:** Botão de Pânico (ESC) para interromper todos os áudios simultaneamente, e controle de Master Volume.
- **Controle de Trilhas e Loop:** Ative loops infinitos para efeitos climáticos ou músicas de fundo e acompanhe as trilhas ativas numa aba dedicada.

## Como Usar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno para rodar a aplicação. Por ser uma solução web cliente-side, não há necessidade de servidor ou banco de dados.
